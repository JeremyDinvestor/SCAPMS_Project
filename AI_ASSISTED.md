# AI-assisted development

This project was built for a university programming course, working together with an AI assistant (Claude by Anthropic).

## How I worked

- **Requirements:** I took the assessment brief and turned it into a plan covering the class design, data structures, algorithms, GUI pages and reports.
- **Direction:** I reviewed the designs and interface previews and decided on the look and feel (modern layout, icons, themes).
- **Environment:** I installed and configured Qt 6, CMake and MinGW, and set up the project in Qt Creator.
- **Testing and debugging:** I built and ran the application, exercised each feature, and worked through build errors with the assistant until the project compiled and ran correctly.
- **Documentation:** I documented the project, including screenshots and a design write-up.

## What the AI did

The AI generated the C++ code, which I reviewed and ran, and helped explain the algorithms and design choices.

## Why I'm sharing this

AI-assisted development is how a lot of software is built today. I'm open about it because directing a tool well, testing the result, and being able to explain it are skills I'm building. I'm comfortable walking through the code and design. If you'd like to talk about the project or work together, feel free to get in touch.
